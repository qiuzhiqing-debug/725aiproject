## 0. 认账：R4 题库为什么被判"最差劲"

三个已查实的硬伤（不是主观）：

1. **算不出理想型分布（建维失败）**：理想型画像是 `ideal-profile.js` 的 **8 维度打分器**算出来的（`DIMENSIONS` + `TAG_DIMENSIONS` tag→维度权重表）。R4 重写题库时用的 tag 一大半**不在 `TAG_DIMENSIONS` 表里**（性癖/强迫症/屁/SM隐蔽/玄学/四爱/道具/角色扮演/空想/渣/淋文化/掰弯/铁T…全部走 `hashTagDimension` 随机兜底）→ **打分向量是噪声，画像形同随机**。Kim：「你不建维你根本没法算分布。」
2. **题目趋同 + 屎尿屁过载**：`卫生` 一个 tag 被用了 **25 次**，重口锅底基本堆在"不讲卫生"这一个点上。Kim：「重口归重口，不是就不讲卫生……只是屎尿屁也没意思。」
3. **锅底无强度梯度、没给低接受度玩家退路**：Kim：「重口里是可以有清汤的……对于接受度低的人来讲，要给她留安全选项，接受度高的也可以玩玩接受度低的游戏。」

## 1. Kim 拍板（R6，已确认不再问）

### 1.1 建维度 = 用现成的 8 维，把题真正接上去
- **不重新发明维度**。沿用 `public/ideal-profile.js` 的 8 维：
  `boundary 边界感 / warmth 情绪价值 / money 金钱观 / play 玩心 / control 掌控欲 / romance 浪漫浓度 / absurd 抽象耐受 / meme 网感`。
- **每题 `tags` 必须至少命中 1 个 `TAG_DIMENSIONS` 已有 key**（多个更好，体现多维信号）。
- 确需新 tag（尤其成人向），**同步在 `ideal-profile.js` 的 `TAG_DIMENSIONS` 加映射**，禁止留 hash 兜底。参考成人向映射方向：
  - 性癖/性偏好 → `{ romance: 0.4, absurd: 0.4 }`（差异化偏好，不是缺点）
  - 道具/角色扮演 → `{ play: 0.5, absurd: 0.4 }`
  - spank/掌控类床事 → `{ control: 0.6, play: 0.3 }`
  - 洁癖/强迫 → `{ boundary: -0.5, control: 0.4 }`
  - （具体由写手定，但**必须落表**）
- 身份类 tag（gay/lesbian/性向…）继续只标"喜欢谁"，**绝不进人格计算**（`IDENTITY_ONLY_TAGS` 已拦，别把取向当维度）。

### 1.2 8 维覆盖均衡（算得出分布的前提）
- **每个模组（满分男/女/老板）**：8 个维度**每维至少有 8 题**带该维度信号（正或负），任一维度不得少于 5 题。目标是任何玩家答完 9-15 题都能在多个维度上拉开差异，画像不趋同。
- 写手交付**维度覆盖自检表**：每维命中题数 + 该维 high/low 两向都有题。

### 1.3 锅底 = 强度梯度带（重定义细化 R4）
锅底名定**上限/主题气质**，但**每个锅底内部 spice 要成梯度**，给不同接受度的人都有得选：

| 锅底 | spice 分布（每 60 题建议直方图） | 说明 |
|---|---|---|
| 清汤 qingtang | spice 1-2 全部 | 全安全，人人能玩，无成人向 |
| 番茄 fanqie | spice 2 约15 / spice 3 约35 / spice 4 约10 | 主体两极分化偏好，含少量安全档兜底 |
| 重口 zhongkou | **spice 2 约10 / spice 3 约15 / spice 4 约20 / spice 5 约15** | **含安全退路（2-3档≈25题）**，signature 是能到 5，但**不是一水儿屎尿屁** |
- **重口去屎尿屁化**：`卫生`/屎尿屁类 tag 全模组合计 **≤6 次**（原 25 次砍掉）。重口的高档要**多样**：性偏好/恋物/床事博弈/权力游戏/抽象性癖…横跨 romance/play/control/absurd 多维，别都压 boundary。
- **安全选项原则**：每个锅底任一 viewer 池里，spice≤3 的题 ≥ 40%，保证低接受度玩家整局都有能自在回答的题。

### 1.4 去趋同 + 调研加码
- **调研 60%**：写手先逛社媒摸黑话/网梗/暗号（60% 时间），再写（30%），再迭代（10%）。发现同质就补学。
- **去趋同硬指标**：同一 tag 组合（排序后）出现 **≤3 次**；每锅底题面开头结构（"TA 总是…/TA 认为…/TA 的…"）不得有单一句式 > 40%。
- 质量关沿用 R4 §1.5：「外人秒懂 + 能脑补画面 + 有惊喜」；旧库题即便对也要升级或归对档。

### 1.5 隔离 & 数量不回退（R4 硬约束保留）
- pools 契约、(gender×seeking)→池 映射**一字不改**（R4 §1.3）。重写 tag/spice **不许动 pools**，隔离铁桶不能破。
- 数量不减：满分男/女每锅底 ≥50（现 60 保持）、满分老板 150 全 neutral、TA 化不默认性别。
