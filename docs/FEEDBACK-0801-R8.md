- **R8-1** 先诊断并回答：当前满分男判型逻辑是什么、重复率高的根因（要有数据，不许口嗨）。

## 三、R8-1 诊断：现状逻辑与重复率根因（已跑数据，见 §六）

**现状逻辑**（`ideal-profile.js`）：
每题 tags → 8 维加权（打分-5 为信号）→ 按 |分值| 排序取 top1/top2 维度 →
称号 = `PERSONA_ADJ[top1][档位] + PERSONA_NOUN[top2][档位]`（24×24=576 理论组合）。
**没有分类层**——称号是自由拼装出来的字符串，不可枚举、不可图鉴、无稀有度。

**重复率高的三个根因**（2000 局模拟证据）：
1. **组合空间虚胖实塌**：576 理论组合只出现 217 种，Top10 称号就占 19%——因为 top1/top2 由「维度权重覆盖面」主导而不是由人主导。
2. **维度不均衡**：control/boundary 类 tag 在题库里覆盖面大，常年霸占 top1 → 「全都安排上的/彻底放养的/不设防的」开头的称号扎堆。
3. **档位阈值粗**：±0.15 三档 + 一局仅 8~12 题小样本 → 大量玩家挤进同档，同档=同词。

**另一个结构缺陷**（对应 R8-4）：生日/职业/身份等档案字段与称号**零绑定**（各自独立 seed 随机），
「多档案指向一个型号」目前是巧合不是设计——图鉴要成立必须把「型号=标签」和「档案=实例」分层定死。

## 四、TYPE-16 设计（fable 定稿）

### 4.1 分层：型号（标签）vs 档案（实例）——回应 R8-4

| 层 | 是什么 | 数量 | 变不变 |
|---|---|---|---|
| **型号层** | 16 个标签：编号 #01-#16、名称、族、一句判词、**型号徽章**（图鉴收藏物，固定视觉） | 每本图鉴 16 | 同分向量永远同型号（确定性可复现） |
| **档案层** | 本局这个具体的「人」：生日/星座/职业/身份/小传/相处细节/**本局立绘** | 无限 | 每局 seed 不同全都不同 |

- 图鉴收集的是**型号徽章**（固定），亮相页展示的是**本局档案+本局立绘**（万变）——
  这样「1994-06-18 和 2006-07-19 都是 #07」成立，且用户永远不会觉得撞见同一个人。
- 档案页明示型号角标「#07 · 人形保险柜」，撞型可聊，细节各异。

### 4.2 判型算法：4 族 × 主导维 × 方向 = 16 桶

8 维分 4 族：**秩序族**（边界+掌控）、**火热族**（情绪+浪漫）、**野生族**（玩心+抽象）、**世俗族**（金钱+网感）。

```
维度分 → 除以该维「题库覆盖归一因子」norm[d]（磨分布的关键，治根因2）
→ 族强度 = |d1'| + |d2'|，取最强族
→ 族内主导维 = |分|大的那个；方向 = 主导维正负（high/low）
→ 型号 = 族(4) × 主导维(2) × 方向(2) = 16，平局按固定序破，全零向量落默认桶
```

`norm[d]` 从题库+人群模拟标定（每维单局可达量级的标准差），**题库、维度、映射一体校准**——
以后加题/改 tag 必须重跑标定，这就是 Kim 说的「题、type、对应逻辑一起有」。

### 4.4 隐藏款
人群验证（§五）跑出的**最稀有 3 型 = 隐藏款**：图鉴里只显示剪影+「？？？」，抽到才揭示。
稀有度是算法+题库+人群的自然结果，不是人工指定——上线后按真实数据周更校验，漂移过大再重标定。

## 五、验证协议（拿人群验证置信度）

- 模拟 N=10000 局/卡组：真实题库随机抽 10 题；玩家分 3 种打分人格（宽容 μ≈7 / 严苛 μ≈4 / 随性 μ≈5.5）加噪声，比均匀分布贴近酒桌真实。
- 通过标准：
  1. 16 型全部可达；
  2. 最大型占比 ≤ 15%（不许一型霸屏）；
  3. 最稀有 3 型占比之和落在 2%~10%（隐藏款要稀有但可达）；
  4. 置信度：bootstrap 重抽 200 次，「最稀有 3 型」名单稳定率 ≥ 90%；
  5. 确定性：同 records 同 seed 永远同型。
- 不达标 → 回炉调 norm 因子/族边界，重跑；达标才准进实现。

### 6.3 定死的算法常数（实现必须逐字用这套）
- `TYPE_ALPHA = 0.7`
