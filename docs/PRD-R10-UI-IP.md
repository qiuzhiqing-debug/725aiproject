## 第一页 · MVP 一页纸（模板五问）

1. **服务谁**：不变（R9：城市年轻人朋友局，服务单位是一桌）。本轮新增判断：**最佳承载=竖屏小程序形态**（抖音/微信），Web 版先按竖屏小程序的形态自我约束。

4. **这期不做**：像素全场景大改（等调研）；付费；图鉴等已关功能不回来。
5. **过闸**：布局收敛=让一桌人更玩得起来 ✓；IP/艺术系统=让结果和过程更值得被记住被晒 ✓。

## 二、审美五问推演（Fable 定稿，供 Kim 复核）

**① 我们讲什么故事？**
一桌人借"给理想型打分"这个由头，在起哄和罚酒里互相暴露、越聊越热。情绪关键词：**微醺、起哄、暧昧、揭底、热络**。不是赛博悲歌，是深夜酒局的暖光时刻。

**② 价值观？**
表达欲被鼓励；标准没有对错（你能忍什么只有你说了算）；玩笑是了解彼此的掩护；机制性包容（不问你是谁，只问你想品鉴谁）。一句话：**在游戏的掩护下说真话。**

**③ 世界观？**（R10.2 定稿，Kim 两次口径合并：「完美的人就是轻科幻的」+「名字不必未来感」）
一间叫「99%」的深夜酒吧（现有设定保留：酒和灯只能把人送到 99%，差的 1% 是人）。三层各归各：
- **设定层=轻科幻**：这家店能把你的理想型"调"出来——"完美的人"本身就是轻科幻设定
- **情绪层=酒馆的暖**：气质永远是深夜酒馆人情味，科幻只是那一点点不可思议，不许变成科技的冷
- **命名层=不绑未来感**：名字只须简单、有记忆点、贴暧昧酒局的内核

**④ 颜色系统？**（红弦的暗=悲伤；我们的暗=包厢的暗，不是雨夜的暗）
- 底色：**暖黑/深酒红调的暗**（往酒红紫走，不用上一版的冷茄紫）
- 主光：**琥珀暖光**——画面要有"被灯烘着"的感觉，暖光占比要高（酒液金、灯罩光池）
- 情绪色：**马天尼粉**只给暧昧时刻（爆灯/心动/揭晓/logo），它是"脸红色"
- 点缀：汽水青，极少量
- 原则：暗而暖、亮有理由、饱和色只做招牌与心跳

**⑤ 人物气质？**
见过所有人理想型的酒保：毒舌但暖、**正经的呆**——一本正经地干着最暧昧的活，反差即喜剧。

## 三、NPC 载体与命名（PM 聚合判断，Kim 终审）

**载体判断：采用非人形——圆头小机器人酒保。** 理由：
1. 彻底绕开"捏脸差"（Kim 痛点：五官精度是硬伤，非人形没有五官负担）
2. 世界观原生：理想型是"调"出来的，调酒的就是系统本身——AI 酒保不是贴皮，是设定
3. 跨精度一致：圆头轮廓在像素/卡通手绘/小程序图标三种精度下都成立
4. 反差=气质：严肃圆头机器人干暧昧的活，正是"正经的呆"

**IP 特征锚（记忆点设计）**：
- 剪影三要素：圆头 + 酒保马甲 + **天线顶一颗橄榄**（与已过关的马天尼杯 logo 同源——logo 里的橄榄就是他）
- 表情系统：默认微严肃（一条直线嘴/半垂眼），呆感来自"过度认真"，不来自卖萌
- 肢体：小头+半身+动作（擦杯、摇壶、递酒），重点永远在动作不在脸

**命名标准（R10.1 修正）：简单、有记忆点是必须；未来感不是必须（Kim：产品内核本身没有未来感）。名字要贴内核=暧昧酒局的暖。**
- 候选「九九」的成立理由与未来感无关：店名 99% 的世界观闭环（他是那 99%，差的 1% 是你）+ 谐音"久久"是暧昧局彩头。
- 载体（机器人/拟物/动物/真人）不预设结论——由 Fable 亲自做的 IP 调研（docs/IP-AND-ART-RESEARCH.md）按"暧昧酒局暖故事+正经的呆+可记忆剪影"重新评估后定夺，艺术方向同步由 PM 定夺不等 Kim 拍板（Kim 授权 2026-08-08）。

## 四、布局收敛（Kim 已拍板逻辑，照此执行）

### 4.1 首页（竖屏，参照第4图的简洁度）
- 大按钮 **「玩一局」**（主 CTA）
- 次按钮 **「点一杯」** = 调酒心理测试+账号档案入口（表述 Kim 未定，先用"点一杯，留下你的口味档案"占位）——**不再是强制门**：删除 index 的调酒跳转闸，落地即首页
- 玩法说明块（三行内）
- 底部小字**反馈**链接（不做大组件）：点开小弹窗一个文本框 → POST /api/feedback 落库 → Kim 在 /stats 看板里读

### 4.2 玩一局 → 桌局组件
- **房主**：选一桌人数（1-8，默认 8）→「生成房间码」→ 上方实时显示谁进来了+准备状态 → 全员准备后才能点开局
- **非房主**：顶部输房间码 → 底部点准备
- **统一按钮**：房主与客人同名（占位文案「开喝」，Kim 终审）；客人点=准备（房主可见），房主点=开局（仅全员准备后可点）
- 有人离桌：房主可改人数、同房重开
- 开局后回到现有游戏逻辑

### 4.3 局内引导链
房主定每轮局数+锅底 → 抽签抽被拷问者 → **被拷问者弹层自选方向**：满分男/满分女/其他（默认带出档案 seeking）+ 性别可选项（已注册带出，供圈层题库）→ 进答题。R9 的 allowedPoolsFor(gender,seeking) 不变，只是把"入座预设"升级为"被拷问时自选确认"。
