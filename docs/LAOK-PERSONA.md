# 老K 人设定稿 v2（全站文案唯一真源）

> 所有系统文案 = 老K在和客人说话。写任何一句 UI 文案前先过这份人设。
> v2 重蒸馏于 2026-07-29，替代一稿。Kim 对一稿的判定："人设还没抓住"。

## 一句话定位

酒吧「99%」的老板。人间戏码看了半辈子，所以什么都不惊讶；话不少，跟谁都能搭两句、接得住任何梗，但从不越界。知世故而不世故——世故长在眼睛里，不长在嘴上。

## 一稿为什么没抓住（诊断，写手必读）

一稿把老K蒸馏成了"沉默寡言金句型"（深夜食堂老板 + 王家卫余味），执行出来就是**装深沉**：每句话都在憋"余味"，像在演一个老板，而不是在开一家店。三个具体病灶：

1. **话太少**。Kim 要的老K是酒吧里那个跟谁都能聊两句的人——客人说什么他接什么，接完顺手回一句自己的。一稿的老K只肯往外扔结论，不接话。
2. **句句要当金句**。真正松弛的人一晚上顺嘴掉一两句好话就够了，剩下都是家常话。一稿每句都想被截图，反而假。
3. **世故写成了"看穿你"**。"你怎么选比你怎么说诚实"这类话，把客人当成被分析对象，隐隐有俯视感。老K的世故是"见过所以不惊讶"，对客人只有好奇，没有诊断。

一句话校准：**老K不是"话少但句句扎心"，是"话不少但句句有分寸"。**

## 蒸馏来源（只取气质，不抄台词）

- 《Cheers》Sam Malone：**主参考升格**。退役浪子开酒吧，跟谁都聊得来，玩笑接得快，但对每个客人都有分寸
- 《老友记》Central Perk 的 Gunther 反例 + 《深夜食堂》老板降格为辅：深夜食堂只取"不评判客人"，不取"话少"
- 香港老茶餐厅伙计的嘴皮子：熟客来了先损一句，损完把你常点的端上来
- 王家卫：**只保留夜色和霓虹，台词全删**。老K不说"从现在开始我们是一分钟的朋友"这种话

## 性格坐标

| 维度 | 是 | 不是 |
|---|---|---|
| 见识 | 什么都见过，所以什么都不惊讶 | 把见过的拿出来讲道理（"我跟你说我见过……"） |
| 话量 | 话不少，客人说什么都能接两句 | 话痨抢戏；也不是惜字如金 |
| 幽默 | 顺着你的话往下接，落点轻，说完就干别的 | 硬抛段子、玩梗轰炸、等你笑 |
| 分寸 | 聊得开但不打听、不评判、不占便宜 | 冷淡疏离，也不是自来熟 |
| 姿态 | 平视。你是客人，他是老板，谁也不欠谁 | 俯视（爹味/分析你）或仰视（讨好/卖萌） |
| 金句 | 偶尔顺嘴掉一句，掉完自己都不在意 | 每句都想被截图 |

## 语言规则（硬约束）

1. **对话体第二人称**。老K在跟"你"说话，不是系统在播报。
2. **一次最多两句**。接话优先于陈述：先接住对方刚发生的事（选了什么、猜了几分），再说自己的。
3. **具体名词 > 抽象大词**。说"冰化了""这杯我记着"，不说"人生""命运""缘分"。大词一出现就像明信片。
4. **装深沉自查**：写完读一遍，这句话如果印在明信片上毫无违和——重写，改成像顺嘴说的。
5. **爹味自查**：像长辈教你做人的，删。老K从不总结人生经验给客人听。
6. **禁登味**：不用"哦~""哟""亲"、波浪号、三连叹号；不自称本店/本系统；老K不发 emoji（系统级画外音除外，如生图等待的"你老公来咯🪽🪽"不是老K说的）。
7. **禁舞台说明**。不写"老K把酒推到你面前："，直接说话。
8. **不解释机制，用酒吧的话包装**。"建房间"→"给你们留张桌子"；"输入密码"→"对暗号"。
9. **介绍一次原则**。老K只在调酒页开场自我引入一次，之后全站默认认识，不再自报家门。
10. **店名与老K分离**。店叫「99%」，不叫"老K的店"；老K是老板，不是招牌。

## 例句基准（60分 vs 90分，12 个场景）

> 注意：部分 60 分例句正是一稿的"90 分"。一稿的高分句在新标准下的病是"憋余味"。

| 场景 | ❌ 60分（播报/装深沉/爹味） | ✅ 90分（老K） |
|---|---|---|
| 开场自介 | 我是老K。在这里，酒比人诚实。 | 来了？我是老K，这店归我管。先陪我调杯酒，你怎么选，我就知道今晚该跟你聊什么。 |
| 问基酒 | 选择你的基酒！／人人心里都有一瓶酒。 | 吧台这排瓶子，总有一瓶对你脾气。第一眼是哪瓶就哪瓶，别替自己想太久。 |
| 摇壶引导 | 请摇晃手机完成调酒 | 料齐了，力气活归你。摇，听见冰响就对了。 |
| 出酒 | 旧码头，酸甜审判。今晚遇到什么人，都别怪酒。 | 好了，尝一口。比你想的顺吧？今晚的运气大概也这样。 |
| 要昵称 | 请输入昵称／告诉我你的名字，故事从名字开始。 | 还没请教怎么称呼。随便报一个，这儿没人用真名。 |
| 要口令 | 请设置4-6位数字密码 | 给自己留个暗号，四到六个数。下次来，换了手机我也认得你。 |
| 昵称重名 | 该昵称已被占用 | 这名字今晚有人用了。换一个，别跟人撞了称呼。 |
| solo 入口 | 单人模式：一人体验完整流程 | 一个人？那你和我聊。吧台这个位置，本来就是留给一个人的。 |
| 等人开局 | 等待其他玩家加入… | 人还没齐。急什么，酒又跑不了。 |
| 罚酒 | 你答错了，罚一杯！！！ | 差得有点远。端起来吧，这杯是你自己猜出来的。 |
| 全场猜偏 | 大家都猜错了哦 | 偏得够远。看来主角的雷区，和你们不在一个片区。 |
| 爆灯 | 恭喜获得爆灯！ | 灯给你亮了。这种事，我一晚上也见不着几回。 |
| 散场 | 游戏结束，感谢游玩 | 今晚就到这儿。杯子放着我收，人你们自己送。 |

## 老K的边界

- 他不参与打分、不站队、不评价任何玩家的人品和理想型。他可以调侃一个选择，但从不调侃选择的人。
- 客人不说的，他不问。所有"看穿"只到眼神为止，说出口的永远是接话，不是分析。
- 他对输赢无所谓，对"人"有兴趣；奖惩都是桌上的规矩，不是他的态度。
- 他不给人生建议。最接近建议的话是"慢点喝"。
- 收尾只送一句话，不总结陈词，不升华。
