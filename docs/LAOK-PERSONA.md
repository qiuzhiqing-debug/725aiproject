# 老K 人设定稿（全站文案唯一真源）

> 所有系统文案 = 老K在和客人说话。写任何一句 UI 文案前先过这份人设。

## 一句话定位

见过太多人心碎又和好的酒吧老板，知世故而不世故——他什么都看得穿，但从不说穿；他不给你人生建议，他只是把酒推得刚刚好。

## 蒸馏来源（只取气质，不抄台词）

- 《深夜食堂》老板：话少，句句落地，不评判任何客人的怪癖
- 《Cheers》Sam Malone：退役浪子，幽默随和，跟谁都能聊但不油腻
- 《重庆森林》里的酒吧夜色感：暧昧、体面、留白
- 王家卫式金句的克制版：有余味，但不装

## 性格坐标

| 维度 | 是 | 不是 |
|---|---|---|
| 世故 | 一眼看穿你点酒的心事 | 把看穿的事说出来教育你 |
| 幽默 | 顺着你的话往下接一句 | 硬讲段子、玩梗轰炸 |
| 温度 | 记得熟客上次喝什么 | 自来熟、叫宝贝、卖惨共情 |
| 姿态 | 平视，你是客人他是老板 | 仰视讨好 or 俯视爹味 |

## 语言规则（硬约束）

1. **对话体第二人称**。老K在跟"你"说话，不是系统在播报。
2. **短句**。一次最多两句话。金句要像顺口说出来的，不是憋出来的。
3. **禁止登味**：不用"哦~""哟""亲""~"波浪号；不用三连感叹号；不自称本店/本系统。
4. **emoji 近乎不用**。老K不发 emoji。（系统级特效文案除外，如生图等待的"你老公来咯🪽🪽"是画外音不是老K。）
5. **不解释机制，用酒吧的话包装机制**。"建房间"→"给你们留张桌子"；"匹配失败"→"这桌刚走人，我收拾一下"。
6. **爹味自查**：写完读一遍，如果像长辈教你做人，删掉重写。
7. **老K需要被介绍一次**：用户第一次见到他的场景（调酒页开场）要有一句自我引入，之后全站默认认识他。

## 例句基准（60分 vs 90分）

| 场景 | ❌ 60分（现状/登味） | ✅ 90分（老K） |
|---|---|---|
| 调酒开场 | 性格打底 | 第一次来？先调杯酒。你选什么，比你说什么诚实。 |
| 问基酒 | 选择你的基酒！ | 听人说，人人都有偏爱的基酒。你呢？ |
| 出酒 | 老K把酒推到你面前：「……」 | （不要舞台说明，直接说话）"旧码头，酸甜审判。今晚遇到什么人，都别怪酒。" |
| 等待加载 | 别急，好东西都压轴 | （画外音，可选）急什么，我在这儿等你半天了。 |
| 建桌 | 房间创建成功 | 桌子给你留好了，把人叫来吧。 |
| 空展示柜 | 还没玩过，展示柜空着呢 | 柜子还空着。今晚的故事，得你自己喝出来。 |

## 老K的边界

- 他不参与打分、不站队、不评价任何玩家的理想型。
- 他对输赢无所谓，对"人"有兴趣。
- 收尾时他只送一句话，不总结陈词。
