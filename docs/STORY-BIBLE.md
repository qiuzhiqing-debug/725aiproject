## 一、故事（我们到底在讲什么）

深夜，一间叫 **「99%」** 的小酒吧。招牌上写着店规：

> **酒和灯只能把人送到 99%，差的那 1%，是个人。**

这家店有个说不清道不明的本事：你在桌上笑着打完一轮分，它就能把你的**理想型**当着全桌人的面调出来——有模有样，有名有姓，像真的存在过。但它永远只能调到 99%。最后那 1%——真正坐到你身边的那个人——店帮不了你，只能靠你自己，或者靠今晚坐你对面起哄的这帮朋友。

所以这个故事不是"寻找完美恋人"，是**一桌人借着品鉴完美恋人，互相看清了彼此**。理想型是由头，酒是道具，真话是产出。

- 情绪关键词：**微醺、起哄、暧昧、揭底、热络**
- 一句话：**在游戏的掩护下说真话。**
- "完美的人"这个设定自带一点轻科幻的不可思议，但整间店的气质是**深夜酒馆的人情味**——那点科幻藏在酒里，不摆在桌面上。

## 二、价值观

1. 表达欲被鼓励：你能忍什么、不能忍什么，只有你说了算，没有标准答案。
2. 玩笑是了解彼此的掩护：起哄和罚酒是这家店的礼仪，不是恶意。
3. 机制性包容：店从不问你是谁，只问你今晚想品鉴谁。
4. 永远差一趴：没有人是 100%，包括这家店自己——所以谁也别装完美。

## 三、酒保 NPC 定稿：**雪克**

### 3.1 名字：雪克（定稿 v3，2026-08-08，Kim 方向：可爱但有意义）
- 取自**雪克杯（Shaker）**——调酒摇壶是他的本职动作，玩家的摇壶调酒、摇签仪式也都是摇。名字=他每天在做的事。
- 音感可爱清爽、两字、有记忆点；与场景强关联但零同义反复（命名负清单继续有效：九八谐音酒吧=场景同义反复被否；马丁偏老派管家不够可爱被替）。
- 天然梗：「你的理想型，是雪克摇出来的。」
- 表情规格 v2（Kim：苦命脸处决）：圆睁完整圆眼（清醒专注），嘴=放松短线带极轻微上扬；正经的呆靠圆睁大眼+过度端正的姿态，不靠半垂眼和苦相。

### 3.2 载体：圆头小机器人酒保（定稿）
选它不是为了萌，是三条结构性理由：
1. **绕开捏脸**：非人形没有五官精度负担——这是老K反复失败的根因，结构性解决。
2. **世界观原生**："能调出完美恋人的店"需要一个说得通的执行者，一台老式调酒机器成精，比一个无名人类酒保更成立。
3. **跨精度剪影**：圆头在图标 16px 到海报尺寸都认得出。

### 3.3 形象规格（给美术执行的硬约束）
- **材质是关键（v2，Kim 2026-08-08）**：**木质为主+黄铜点缀的老式机器**——雪克是全场唯一最适合木质的东西（Kim 原话）；机身不透明（透明=吓人=bug）。UI 组件禁木纹的规矩不变：木头只长在雪克和场景实体物件上。绝不是白色科技感。
- 剪影三要素：**圆头 + 酒保马甲(或围裙) + 天线顶一颗橄榄**（与已过关的马天尼杯 logo 同源——logo 里那颗橄榄就是他）。
- 表情：**正经的呆**——见 3.1 表情规格 v2（圆睁圆眼+放松短线嘴），呆感来自"过度认真"，永不卖萌、永不方头、永不苦相。
- 身体：小头+半身+动作（擦杯、摇壶、递酒、记小本本），镜头重点永远在动作不在脸。
- 性格：见过所有人的理想型，毒舌但暖；对酒极度严肃，对暧昧装作不懂（其实全懂）。

## 四、颜色系统（从故事推出来，不从参考图抄）

红弦俱乐部的暗是**雨夜的暗**（悲伤故事）；我们的暗是**包厢的暗**（暧昧故事）。

| 角色 | 颜色 | 用途 |
|---|---|---|
| 底色 | 深夜紫黑（#14101f 方向）·R11 v2：Kim 判暖木质=威士忌吧太安静，回归霓虹能量 | 全局背景，"霓虹洗墙的店" |
| 主光 | 霓虹粉/电紫/汽水青（R11 v2 升为主光源），琥珀降为吧台小台灯点缀 | 情绪目标：兴奋、起哄、心跳——不是安静高级 |
| 心动色 | 马天尼粉 #ff2d78（logo 已过关，不动） | **只给心动时刻**：爆灯、揭晓、亮相、logo。它是"脸红色"，滥用即贬值 |
| 点缀 | 汽水青 #2de2ff | 极少量，霓虹小招牌级别 |
| 材质 | 深木、黄铜、玻璃、绒布 | 组件的"物质感"来源 |

原则：**暗而暖、亮有理由、饱和色只做招牌与心跳。**

## 五、美术与 UI 方向（PM 定稿，Kim 授权不等拍板）

- **全站统一：卡通手绘暖色系、场景化 UI**（动物餐厅级工艺方向：竖屏原生、界面长进世界里）。像素风退役——竖屏小程序表现力受限（Kim 判断+调研支持），红弦的气质用手绘的光影语言继承：暗而暖、光影叙事、霓虹只做招牌。
- **组件拟物到酒吧物件**：题卡=吧台菜单板；按钮=杯垫/黄铜牌；房间码=包厢门牌；准备状态=酒杯满上；锅底选择=灶台三档火；进度=酒液刻度。用户第一眼就懂每个组件是什么（Kim 目标③：直白但有意思）。
- 雪克用同一手绘语言绘制（几何圆头机器人不存在精度难题），马天尼杯 logo 原样保留。
- 生图（亮相立绘）流水线不变，属于"店调出来的人"，风格独立成立。

## 五点五、海报法则（Kim 方法论定稿 2026-08-08）

**海报必须和 UI 同一个系统，二选一，不许骑墙：**
- UI 低价 → 海报走**嘲弄风**：故意的重 AI 味劣质男女，配「你老公来咯🪽」语气暗示"我们是故意的"，酒桌互相嘲笑即价值。最忌讳：让人觉得你很努力结果审美还差。
- UI 精致 → 海报走**审美风**：有风情的男人女人，与 UI 同色彩系统同气质，可作产品特色。
- **现行模式（R11 定）：生图质量未到审美线 → 走嘲弄风**——提示词回退第一版满分男（劣质AI味好笑那版），生图等待页大字「你老公/老婆/TA来咯」+🪽🪽居中=「我们是故意的」信号。质量哪天配得上审美风再切换。「来咯🪽」永久保留。
- 海报二维码 → 站点落地首页（链路第一环），不进房间（Kim 2026-08-08 定）。
