# IP 与美术方向调研（Fable 亲笔，2026-08-08 夜）

> 给 Kim 直接读的版本。结论已按调研落进《STORY-BIBLE.md》（定稿）。本文讲**为什么这么定**，带证据；标注了哪些是检索求证、哪些是我的专业判断（未联网验证）。

## 一、经典 IP 方法论：小体量抄得动的五条

（案例为业界公认事实，方法提炼是我的判断）

1. **剪影测试**：皮卡丘/米老鼠涂成纯黑仍三秒可认。IP 的第一资产是轮廓不是细节。→ 九八的剪影三要素：圆头+马甲+橄榄天线，涂黑仍认得出。
2. **三色纪律**：经典角色主体色不超过三个（皮卡丘=黄+红颊+棕纹）。→ 九八=黄铜+马甲深色+橄榄绿，完。
3. **签名道具**：路飞的草帽、马里奥的帽子——道具可以脱离角色单独存在并指回角色。→ 橄榄天线与马天尼杯 logo 同源：**logo 里那颗橄榄就是他**，用户先认识 logo 再认识他，道具已预埋。
4. **缺陷设计**：完美角色记不住。Duolingo 的猫头鹰靠"过度认真到吓人"成为最出圈的 App IP（近年最成功的"正经的呆"案例）。→ 九八的缺陷=他自己只有 98%，比店还差一趴；呆感来自过度认真。
5. **跨精度一致**：任天堂角色从 16px 图标到海报视觉不崩。→ 圆头几何形体天然满足；这也是放弃"写实人脸酒保"的硬理由——人脸在小尺寸必崩，我们已两次踩坑。

## 二、爆火小程序/治愈系的视觉共性（检索求证）

- **动物餐厅**：Q 萌手绘、清新简约、暖色调营造治愈氛围；界面元素全部长在餐厅场景里（招牌/菜单/信箱都是"物件"），玩法做减法不做资源压力（[知乎](https://zhuanlan.zhihu.com/p/109330558)、[人人都是产品经理拆解](https://www.woshipm.com/pd/4568490.html)、[CSDN UI 连载](https://blog.csdn.net/wugekaipao/article/details/121689348)）。
- 共性规律：**竖屏原生、手绘、暖色、组件拟物到世界里、无裸露网页部件**——这正是"UI 不削弱沉浸感"的实现方式。
- 羊了个羊：美术平庸，爆红靠机制与社交裂变——反证**美术不是爆红充分条件，但"组件直白"是底线**。

## 三、酒吧题材的气质参照（检索求证）

- **VA-11 Hall-A**：PC-98 复古像素+赛博霓虹，情绪=孤独疗愈（[TheSixthAxis 评测](https://www.thesixthaxis.com/2019/05/03/va11halla-review-cyberpunk-bartender-action/)）。
- **Coffee Talk**：刻意避开 VA-11 的紫调，走 90 年代动画暖调，有限色板，气质=深夜暖谈（[MoeGamer 分析](https://moegamer.net/2020/01/28/coffee-talk-its-a-brewtiful-day/)、[Bits & Pieces](https://bitsandpieces.games/2020/11/13/coffee-talk-review/)）。
- 启示：**同是深夜吧台，色调跟着故事走**——悲伤=冷紫雨夜，暖谈=琥珀灯光。我们讲暧昧热络，故事圣经因此定"包厢的暗"，这条推导链与红弦（悲伤→暗红雨夜）同构而结论不同。这正是"抄气质不抄表面"。

## 四、竖屏像素可行性（检索求证 + 判断）

- 检索微信小游戏生态：竖屏适配资料多（750×1334 设计稿、刘海/胶囊避让），**未发现有分量的竖屏像素爆款案例**（[适配策略](https://juejin.cn/post/7457091128305238079)、[爆款小游戏体验设计](https://zhuanlan.zhihu.com/p/22057189288)）。
- 我的判断（未验证为绝对，但证据一致）：像素的表现力依赖横向场景纵深与整屏氛围，竖屏窄画幅+胶囊遮挡会把它挤成"低清"而非"复古"；Kim 的直觉（像素不适合小程序、手绘更适合）**成立**。
- 结论：**像素退役，全站手绘**；红弦气质由光影与色彩系统继承，不由像素颗粒继承。混搭（手绘场景+像素 NPC）虽然 Kim 可接受，但统一语言的高级感上限更高，且圆头机器人用手绘毫无精度难题——混搭的唯一理由消失了。

## 五、命名（按 Kim 原则：强关联、不重复）

- 否决「小99」类（与店名重复无效，Kim 明示）。
- **定稿「九八」**：谐音**酒吧**（念名字=念这家店的本质）；数字上比 99% 差一趴（缺陷设计，见 §一.4）；两个字顺口，酒桌喊得出来。
- 备选记录（已比较后放弃）：「一趴」——1% 在店规里属于"人"，给机器人用会拧断世界观；「OK仔」——与店无关联。

## 六、三个定案（已写入 STORY-BIBLE.md）

1. **美术方向**：全站卡通手绘暖色、场景化 UI（组件拟物到酒吧物件），色彩系统=暖黑酒红底+琥珀主光+马天尼粉只给心动时刻。风险：手绘工艺执行不到位会掉回"普通小程序"——用材质（木/黄铜/玻璃/绒布）和光影层次顶住精度。
2. **NPC**：黄铜老机器成精的圆头酒保，正经的呆，橄榄天线接 logo。风险：机器人做冷了会脱离酒馆气质——材质锁黄铜+木，禁白色科技感。
3. **名字**：九八。风险：极低（商标粗查无从线上确认，标注未验证；两字数字名冲突概率小）。
