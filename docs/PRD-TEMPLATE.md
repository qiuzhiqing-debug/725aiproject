# PRD 模板（2026-08-01 起强制）

> 教训：满分男第三周才定出 MVP。旧 PRD 只答"怎么做对"，不答"为什么做"。
> 从今往后，第一页答不全，第二页不许写。

## 第一页 · MVP 一页纸（先答这五问）

1. **服务谁**：场景里的具体人群（"一桌 3-6 人的朋友局"，不是"年轻用户"）
2. **核心假设**：可证伪 + 数字口径（如"完局率≥60%，14天复开率≥30%"）
3. **北极星指标**：一个，品类决定形状（酒桌品类=周完局桌数，不是日活）
4. **这期不做什么**：负清单，和功能清单同等份量，写明"关不删"还是"不建"
5. **功能过闸**（每条功能逐条过）：它让一桌人更玩得起来？还是让结果更值得被晒？两个都不是→砍或进冷宫

## 第二页起 · 才是原来的东西

反馈原话 → 编号复述 → 功能拆解 → 文件所有权分工 → 验收标准（数据+截图）→ 部署与回滚
