# UI-BRIEF R9 · 去廉价感重设计（Fable 定稿，Opus 执行）

Kim 原话：底纹交叉格纹「老会有一种努力的廉价感——好像非常努力想做一个很精致的东西出来，其实很低级」。
要求：理解为什么廉价 → 解掉 → 做一版不会再触发这个感觉的。风格由 PM 定夺，不问 Kim。**文案一个字不许动。**

## 一、诊断：廉价感的三个来源

1. **满屏重复格纹**：高频重复纹理铺满 100% 视口 = 模板感 + 视觉噪音。它在每个像素上喊"我是赛博风"，这正是"努力感"的本体。高级的暗色界面敢于大面积什么都不放。
2. **霓虹滥用**：多种饱和色同权重、处处发光描边。当所有东西都在发光，就没有东西在发光——发光失去了"这里重要"的语义，只剩"我很努力"。
3. **无层级**：盒子靠 1px 霓虹边框林立区分、纹理压在正文底下。层级靠亮度和留白建立，不靠描边。

一句话：**廉价感 = 装饰密度替代了设计决断。解法 = 克制——暗得下去、亮得有理由、留白敢留。**

## 二、新视觉系统（已定稿，不再讨论）

### 2.1 背景（第一优先级）
- **删除一切重复格纹/网格纹理**（theme.css/style.css 里的 repeating-linear-gradient 网格、grid 背景类，从源头删）。
- 基底：近黑深茄紫（#0b0710 量级）**纯色**。
- 深度用光不用纹理：两团巨大固定径向渐变——左下暖琥珀（酒吧灯感）、右上冷紫青（霓虹侧光），各 ≤8% 不透明度，fixed 不随滚动重复。
- 可选一层 2% 不透明度的细噪点（单张大尺寸 SVG noise，不能有肉眼可辨的重复感）。除此之外背景什么都没有。

### 2.2 霓虹预算（硬约束）
- 主强调色一个：马天尼粉 #ff2d78；辅助色一个：青 #2de2ff。其余颜色一律降饱和入灰紫。
- 发光（text/box-shadow glow）只允许出现在三处：logo、主 CTA、激活态。其它一切元素哑光。

### 2.3 面层与排版
- 面板：比基底亮一档的紫灰面 + 统一 16px 圆角 + 柔和投影；**默认无边框**（边框只留给输入框与 focus 态）。
- 字体：像素字只用于 logo/大标题；正文切系统无衬线，行高放松，区块间距加大一档。
- 按钮：主按钮实心强调色；次按钮哑光面层，不做霓虹描边。

### 2.4 老K 形象重设计（bartender.js 像素画重绘）
- 保持像素身份与暖笑（Kim 之前否过沧桑脸），但工艺升级：逻辑格 16px→24-32px，轮廓收干净。
- 调色板收紧到 8-10 色，与新主题同源（茄紫基底/琥珀暖光/马天尼粉/青）。
- 单一暖色主光源（吧台灯方向），背景酒柜简化——竞争性霓虹招牌减到一块（马天尼牌），暗部敢暗。

### 2.5 范围
cocktail/v2 全链 + 游戏主界面（首页/房间/答题/揭晓/亮相/海报页面框架）。所有页面同一套语言，不许出现新旧混搭页。
