# 题库 V2 规格（所有题库子线程共同遵守）

## 文件与导出
- 目录 `public/questions-v2/`，一个模组一个文件：`lover.js` `boss.js` `agent.js` `roommate.js` `teacher.js`，国王题 `king.js`
- ES module，导出：

```js
export const MODULE = {
  key: "lover",            // 模组 key
  name: "满分爱人",         // 展示名
  noun: { m: "满分男", f: "满分女", n: "满分TA" }, // 题面前缀用
  desc: "一句话模组介绍",
  decks: {
    qingtang: { name: "清汤锅底", desc: "...", questions: [...] },
    fanqie:   { name: "番茄锅底", desc: "...", questions: [...] },
    mala:     { name: "麻辣锅底", desc: "...", questions: [...] },
  },
};
```

- 题目 schema：`{ id, spice, tags: [...], pools: [...], m, f, n }`
  - `id` 全局唯一，规则 `模组前缀+锅底字母+序号`，如 lover 用 `lv-q001` `lv-f001` `lv-m001`，boss 用 `bs-q001`…（agent=`ag` roommate=`rm` teacher=`tc` king=`kg`）
  - `spice`：清汤 1-2，番茄 3，麻辣 4-5
  - `pools`（取向池，杜绝"选男生却混入不该出现的题"）：
    - `["all"]` 全员通用（任何视角读都成立且好笑）
    - `["straight-f"]` 直女视角看男友 / `["straight-m"]` 直男视角看女友
    - `["gay"]` 男同语境 / `["lesbian"]` 女同语境
    - 可组合如 `["straight-f","gay"]`（看男性对象但直女和男同都懂的梗）
  - `m`/`f`/`n`：题面后半句。前端拼「这是一个满分男，但{m}」/「…满分女，但{f}」/「…满分TA，但{n}」。**三个都必须写**。
  - **句式铁律（Kim 2026-07-28 二次纠正，QA 脚本强制）**：所有模组统一句式「这是一个满分XX，但他XX」。因此 **m 必须以「他」开头、f 必须以「她」开头、n 必须以「TA」开头**，拼出来才是「…但他面试在酒吧」这样的原味句子。不分性别的模组（boss/agent）内容三份相同，但代词照样换：m=「他要你帮他拿外卖」f=「她要你帮她拿外卖」n=「TA要你帮TA拿外卖」。禁止写成不带主语或以其他词开头的后半句。

## 数量硬指标（QA 脚本 `node qa/questions-qa.mjs` 会验，不绿不许交）
- lover：每个（锅底 × 4 个取向池）可用题 ≥35（含 all 池共享），即清汤给 straight-f 能抽出 ≥35 道，等等
- 其他模组：每个锅底 ≥35 道（不分池，pools 全填 `["all"]`，但涉及性缘的题要按池标）
- king.js：`export const KING_QUESTIONS = [{id, text}]` ≥40 道（国王游戏用：国王对指定人的提问/指令，酒桌尺度，好笑不越界，如「让你左边的人模仿你的微信语音开场白」）
- 同模组内**跨锅底**文案也不许重复

## 质量标准（这是产品的命）
- 幽默 > 猎奇。每题都要「会心一笑」，网梗浓度高但**一桌至少一人听得懂**，禁止全桌冷场的深梗
- 标杆例题（Kim 给的）：
  - 幽默：「这是一个满分男，但他和你吵架用 DeepSeek」
  - 经典：「这是一个满分女，但送异性朋友的礼物比送你的贵五倍」
  - 模棱两可（制造酒桌争论，占比 ~20%）：「这是一个满分男，但他用和前女友的矛盾和朋友玩满分女游戏」
  - lesbian：「这是一个满分女，但她是乙游受众」
  - gay：「这是一个满分男，但他是福瑞控」
- 麻辣锅必须真的重口（成年人后果自负级：前任/金钱/性边界/隐私背叛），但重口≠下流，要又损又好笑
- 包容性：题库整体容纳顺直/gay/lesbian/跨性别视角，但**不显眼**——通过 pools 隔离实现，不在题面上贴标签。避免刻板印象羞辱（梗可以损具体行为，不损身份本身）
- 2025-2026 网感：AI 味、搭子文化、发疯文学、班味、精神状态、City、恋综、短剧、小红书判案、MBTI 玄学等都是好素材；过气老梗（蓝瘦香菇级）禁用
- 现有 v1 题库在 `public/questions.js`（60 道恋爱向），lover.js 可吸收改写其中的好题（id 换新规则），其余模组全新写

## 各模组延伸思路（参考恋爱向分支法：把"具体行为的反差"作为句式引擎）
- boss 满分老板：画饼/PUA/伪扁平/福报文化/团建/裁员美学/朋友圈点赞考核（视角=打工人看老板）。**不分男女老板**：noun 统一 {m:"满分老板", f:"满分老板", n:"满分老板"}，题面 m=f=n 写同一句即可（Kim 2026-07-28 指示）
  - **Kim 亲自给的标杆（注意风格：短、直、狠，一句话戳到位，不堆修饰）**：
    - 「这是一个满分老板，但他面试在酒吧」
    - 「这是一个满分老板，但他要你帮他拿外卖」
    - 「这是一个满分老板，但他看不起你」
    - 「这是一个满分老板，但他私生活混乱」
  - 注意梯度：像「看不起你」「私生活混乱」这种五个字见血的钝刀题和具体场景题（面试在酒吧）要混着来，不能全是长句网梗。量要厚，35 是底线不是目标，奔着 50/锅底写
- agent 满分Agent：AI 打工人梗——幻觉/道歉循环/自信地错/删库/提示词玄学/「你说得对，但是」（视角=用户看 AI 助手，自嘲我们自己）
- roommate 满分室友：卫生/噪音/公共物资/带对象回来/水电费/冰箱政治（视角=合租人）
- teacher 满分老师：拖堂/占课/双标/画饼/查手机/家长群表演（视角=学生）
